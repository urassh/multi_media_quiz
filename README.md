# マルチメディア記述法 クイズアプリ

東京都市大「マルチメディア記述法」の期末テスト対策用クイズアプリ。
第1〜13回の講義内容 + 先生のテスト参考資料をもとに約200問を収録。

## クイズタイプ

- **4択**: 選択肢から1つ選ぶ (選択肢は毎回シャッフル)
- **数字入力**: 解像度・周波数・バイト数などの数値を入力
- **用語入力**: 用語を直接入力 (表記ゆれは正規化して判定)
- **記述**: 先生の文章問題を白紙から書く練習。模範解答と照合し、採点ポイントを自己チェックして採点 (7割以上で正解扱い)

## 機能

- 出題範囲 (講義回) と問題タイプで絞り込み
- 出題数の選択 (10 / 20 / 30 / 全部)、出題順はランダム
- 回答直後に正誤 + 解説を表示
- 結果画面で振り返り、間違えた問題だけのやり直し

## 開発

```sh
npm install
npm run dev      # 開発サーバ
npm run build    # 型チェック + 本番ビルド (dist/)
```

## デプロイ (Vercel)

Vite プロジェクトとしてそのままデプロイ可能。

- Framework Preset: **Vite**
- Build Command: `npm run build`
- Output Directory: `dist`

## 問題の追加・修正

クイズデータは科目ごとに `data/multi_media.json` (マルチメディア記述法)・`data/network_security.json` (ネットワークセキュリティ) に格納している。科目の追加は `src/questions.ts` の `SUBJECTS` に登録する。

```jsonc
{
  "lectureLabels": { "1": "第1回 イントロ・標準化", ... },
  "questions": [ { "id": "l01-01", "lecture": 1, "topic": "...", "type": "choice", ... } ]
}
```

問題を追加・修正する場合はこの `questions` 配列を編集する。各タイプが持つフィールドの定義は `src/types.ts` の `Question` 型を参照 (`src/questions.ts` が JSON を読み込んで型を付けている)。
